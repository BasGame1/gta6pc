### What and why

Under Wine, `D3D12SerializeRootSignature` and `D3D12SerializeVersionedRootSignature`
return blobs whose 16-byte DXBC MD5 checksum is all-zero (confirmed on Wine 9.0 and 11.0
with both legacy and versioned calls). When the runtime forwards such a blob to
`D3D12XboxSerializeRootSignature` / `D3D12XboxSerializeVersionedRootSignature` on the host,
the host rejects it with `E_INVALIDARG` because it verifies the checksum before
deserializing.

`copy_dxbc_blob_fill_zero_checksum()` in `d3d12_xs_rootsig.cpp` detects the zero-hash
pattern (magic `DXBC`, 16-byte hash field all zero, `total_size` field matching the buffer
length) and recomputes the MD5 checksum with the existing `dxbc_checksum()` helper before
the host call. Both the unversioned path in `d3d12_xs.cpp` and the versioned path in
`d3d12_xs_rootsig.cpp` call it; unaffected blobs (non-zero checksum) pass through unchanged.
