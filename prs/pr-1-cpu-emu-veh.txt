### What and why

The Xbox Series executable uses AVX2, FMA, F16C, BMI1/BMI2, POPCNT, MOVBE, and SSE4.1/4.2
instructions. On CPUs that predate any of those extensions (pre-Haswell Intel, pre-Zen AMD,
some older Xeon), the game crashes on its first #UD before it reaches the title screen.

This adds `runtime/src/cpu_emu.h`, a portable decoder/executor for the affected encodings
in the namespace `rt::cpu_emu`. On Windows, a VEH handler (`cpu_emu::install_handler`) is
registered from `main` when the host CPU is missing any extension or when
`LEONIDA_CPU_EMU=1` is set. The handler catches `EXCEPTION_ILLEGAL_INSTRUCTION`, decodes
the failing instruction (REX + VEX2/VEX3/EVEX/legacy prefixes, ModRM, SIB, displacement,
immediate), executes it against a `CpuState` that mirrors the thread's CONTEXT, and resumes
after it.

Supported encodings: all 256-bit YMM forms of the following extension groups and all their
128-bit XMM variants:
- AVX / AVX2: VMOVDQU, VMOVDQA, VPAND, VPOR, VPXOR, VPANDN, VPUNPCK{L,H}{BW,WD,DQ,QDQ},
  VPACK{S,U}S{WB,DW}, VPALIGNR, VPSHUFD, VPSHUFB, VPSLL{W,D,Q}, VPSRL{W,D,Q}, VPSRA{W,D},
  VPINSRB/W/D/Q, VPEXTRB/W/D/Q, VPCMPEQ{B,W,D,Q}, VPCMPGT{B,W,D,Q}, VPMOVMSKB,
  VPBLENDVB, VPBLEND{W,D}, VPERMD, VPERM2I128, VINSERTI128, VEXTRACTI128, VBROADCAST{SS,SD,I128}
- FMA: VFMADD{132,213,231}{PS,PD,SS,SD}, VFMSUB variants
- F16C: VCVTPH2PS, VCVTPS2PH
- BMI1/BMI2: ANDN, BEXTR, BLSI, BLSMSK, BLSR, TZCNT, LZCNT, BZHI, MULX, PDEP, PEXT, RORX,
  SARX, SHLX, SHRX
- POPCNT: POPCNT r/m 16/32/64
- MOVBE: MOVBE r, m and MOVBE m, r (all sizes)
- SSE4.1/4.2: PBLENDVB, BLENDVPS/PD, DPPS/DPPD, MPSADBW, PCMPEQQ, PINSRB/W/D/Q,
  PEXTRB/W/D/Q, PMAXSB/UW/SD/UD, PMINSB/UW/SD/UD, PMULLD, PTEST, PCMPESTRI/ESTRM/ISTRI/ISTRM

A `cpu_emu_test.cpp` covers the full instruction list, the REX / VEX2 / VEX3 prefix paths,
memory operands, and partial register writes on 32-bit destinations. The VEH path is tested
by raising #UD explicitly with `__ud2()` from a guarded thread and checking that CONTEXT
shows the updated register value on return.

### Tested

Linux + Wine 11.22, RTX 5060, driver 575.51.02. No game files needed.

- `cmake -S runtime -B runtime/build/linux && cmake --build runtime/build/linux`
- `ctest --test-dir runtime/build/linux --output-on-failure -R "^cpu_emu$"` → 1/1 passed
- Windows cross-build (clang-cl, --target=x86_64-pc-windows-msvc):
  `cpu_emu_test.exe` under Wine: all checks passed (emulated path forced with LEONIDA_CPU_EMU=1)
- `python -I scripts/check_no_game_data.py runtime/src/cpu_emu.h runtime/test/cpu_emu_test.cpp runtime/CMakeLists.txt runtime/src/main.cpp` → exit 0
- `python -m compileall -q make_game.py tools tests` → 0 errors

AI-assisted. Tested on Linux + Wine 11.22 + RTX 5060 (Arch Linux, kernel 6.14, AMD Ryzen 9 7950X).
