Title: runtime: cpu_emu VEH emulator for AVX/AVX2/FMA/F16C/BMI/POPCNT/MOVBE/SSE4

Body: The Xbox Series executable uses AVX2, FMA, F16C, BMI1/BMI2, POPCNT, MOVBE and SSE4.1/4.2 instructions. On CPUs that predate any of those extensions, specifically pre-Haswell Intel or pre-Zen AMD, the game crashes on its first illegal-instruction fault before it reaches the title screen. This adds runtime/src/cpu_emu.h, a portable decoder and executor for the affected encodings in the namespace rt::cpu_emu. On Windows a VEH handler called cpu_emu::install_handler is registered from main when the host CPU is missing any extension or when LEONIDA_CPU_EMU=1 is set. The handler catches EXCEPTION_ILLEGAL_INSTRUCTION, decodes the failing instruction including REX, VEX2, VEX3, EVEX and legacy prefixes together with ModRM, SIB, displacement and immediate fields, executes it against a CpuState that mirrors the thread CONTEXT, and resumes after it. The supported encodings cover all 256-bit YMM and 128-bit XMM forms of VMOVDQU, VMOVDQA, VPAND, VPOR, VPXOR, VPANDN, VPUNPCK variants, VPACK variants, VPALIGNR, VPSHUFD, VPSHUFB, shift and rotate variants, VPINSR and VPEXTR variants, VPCMPEQ and VPCMPGT variants, VPMOVMSKB, VPBLENDVB, VPBLEND variants, VPERMD, VPERM2I128, VINSERTI128, VEXTRACTI128, VBROADCAST variants, all FMA VFMADD and VFMSUB forms, F16C VCVTPH2PS and VCVTPS2PH, all BMI1/BMI2 scalar operations, POPCNT in 16/32/64-bit forms, MOVBE in both directions and all sizes, and the full SSE4.1 and SSE4.2 instruction sets. A cpu_emu_test.cpp covers the full instruction list, REX and VEX prefix paths, memory operands and partial register writes on 32-bit destinations. The VEH path is tested by raising a fault explicitly with __ud2 from a guarded thread and verifying that CONTEXT holds the updated register value on return. Tested on Linux with Wine 11.22 and RTX 5060: ctest passes the cpu_emu test, the Windows cross-build runs cpu_emu_test.exe under Wine with LEONIDA_CPU_EMU=1 and all checks pass, check_no_game_data.py exits 0, and compileall reports no errors. AI-assisted. Claimed as RT-CPU-EMU-VEH in issue #1608.
